چطور این پروژه را در GitHub منتشر کنیم
======================================

نکته مهم: مخزن GitHub فقط کد و فایل‌های نصب را نگه می‌دارد. مدل صوتی در زمان نصب مستقیماً از Hugging Face دریافت می‌شود؛ بنابراین لازم نیست فایل 484 مگابایتی مدل را به GitHub آپلود کنید و سرور شخصی هم نیاز نیست.

روش آسان برای مبتدی‌ها: GitHub Desktop
--------------------------------------
1. وارد https://github.com شوید و یک repository جدید بسازید.
2. نام پیشنهادی: voice-typing-offline
3. مخزن را Public انتخاب کنید، اگر می‌خواهید همه بتوانند آن را دریافت کنند.
4. اگر می‌خواهید کد را آزادانه در اختیار دیگران بگذارید، پیش از انتشار دربارهٔ license تصمیم بگیرید. در بسته هیچ مجوزی از طرف شما انتخاب نشده است.
5. GitHub Desktop را از https://desktop.github.com دانلود و نصب کنید.
6. مخزن جدید را از GitHub به کمپیوتر خود Clone کنید.
7. فایل‌های این بسته را داخل پوشه مخزن Clone‌شده کپی کنید. اگر GitHub هنگام ساخت مخزن فایل README ساخته است، قبل از جایگزین‌کردن آن نسخه را بررسی کنید.
8. این فایل‌ها را هرگز منتشر نکنید:
   - .venv و هر پوشه محیط مجازی Python
   - فایل‌های مدل در models\small
   - محتویات data (تاریخچه و تنظیمات شخصی)
   - backend\local_config.json (توکن خصوصی همان کمپیوتر)
   - install-pip.log و فایل‌های log دیگر
9. فایل .gitignore در بسته، موارد بالا را مستثنا می‌کند. آن را نگه دارید.
10. در GitHub Desktop پیام کوتاهی مانند "Initial release" بنویسید، Commit را بزنید و سپس Push origin را انتخاب کنید.
11. صفحه repository را در مرورگر باز کنید و README.md را بررسی کنید.
12. اگر می‌خواهید کاربران فقط یک فایل کوچک را از GitHub بگیرند، فایل DOWNLOAD_AND_INSTALL_FROM_GITHUB_TEMPLATE.bat را در Notepad باز کنید و مقدار YOUR-USERNAME/voice-typing-offline را با نام واقعی مخزن خود عوض کنید. نام branch را نیز main تأیید کنید. سپس تغییر را Commit و Push کنید. تا پیش از واردکردن نام واقعی repository، این فایل فقط یک template است و نباید برای استفاده‌کنندگان منتشر شود.

روش مرورگر
-----------
برای چند فایل کوچک می‌توانید در مخزن از Add file > Upload files استفاده کنید. اما برای پوشه‌ها و نگهداری نسخه‌ها، GitHub Desktop یا Git از خط فرمان راحت‌تر است.

کاربری که پروژه را دریافت می‌کند
--------------------------------
کاربر از صفحه GitHub گزینه Code > Download ZIP را می‌زند، ZIP را استخراج می‌کند و روی Install_Voice_Typing.bat دوبار کلیک می‌کند. نصب‌کننده Python سازگار، کتابخانه‌ها و مدل Small را آماده می‌کند. دانلود نخست به اینترنت و فضای خالی کافی نیاز دارد.

محدودیت فایل‌های بزرگ
---------------------
GitHub برای فایل منفرد در مخزن عادی محدودیت 100 MB دارد. Git LFS و فایل‌های Release قوانین جداگانه، سقف فایل و شرایط ذخیره‌سازی/پهنای‌باند دارند. برای این پروژه، راه بهتر آپلود نکردن مدل در GitHub و دانلود مستقیم آن از Hugging Face است.

راهنمای نصب و اجرای Voice Typing Offline
========================================

این پروژه برای ویندوز است. نصب‌کننده کتابخانه‌های لازم را نصب و مدل Faster-Whisper Small را از اینترنت دریافت می‌کند.

پیش از نصب
----------
1. ویندوز 64 بیتی توصیه می‌شود.
2. اتصال اینترنت داشته باشید.
3. حداقل حدود 3 گیگابایت فضای خالی فراهم کنید. حجم نهایی به نسخه‌های کتابخانه‌ها و فایل‌های دانلودشده بستگی دارد.
4. فایل ZIP پروژه را کامل استخراج کنید. برنامه را مستقیماً داخل پنجره ZIP اجرا نکنید.

نصب با یک فایل
--------------
1. به پوشه‌ای بروید که فایل Install_Voice_Typing.bat در آن قرار دارد.
2. روی Install_Voice_Typing.bat دوبار کلیک کنید.
3. پنجره سیاه CMD را نبندید. نصب‌کننده نسخه سازگار Python را پیدا می‌کند یا Python رسمی را دانلود و نصب می‌کند.
4. سپس محیط مجازی .venv، کتابخانه‌های Python، بک‌اند، و مدل Small نصب یا آماده می‌شوند.
5. پس از تکمیل مراحل، برنامه دسکتاپ به‌صورت خودکار باز می‌شود.

اجرای دفعات بعد
---------------
- برای بازکردن برنامه بدون پنجره CMD، روی Start Voice Typing.vbs دوبار کلیک کنید.
- برای دیدن پیام‌های فنی در CMD، از Run_Voice_Typing.bat استفاده کنید.
- بک‌اند اختیاری است. اگر به API محلی نیاز دارید، Run_Backend.bat را اجرا کنید.

مدل و کار آفلاین
----------------
- نصب‌کننده مدل Systran/faster-whisper-small را دریافت می‌کند.
- مدل در پوشه models\small ذخیره می‌شود. رابط برنامه کوچک‌تر و واکنش‌گرا است؛ دکمه‌های Start recording و Stop & transcribe در نوار ثابت پایین پنجره قرار دارند. برای تغییر اندازه پنجره می‌توانید لبه‌های آن را بکشید. فایل app.ico آیکن اختصاصی پنجره را فراهم می‌کند.
- برای دانلود اولیه کتابخانه‌ها و مدل به اینترنت نیاز است.
- پس از نصب موفق، تشخیص گفتار در برنامه دسکتاپ به‌صورت محلی اجرا می‌شود و معمولاً برای پردازش فایل صوتی به اینترنت نیاز ندارد.
- برای دریافت دوباره یا تکمیل دانلود ناقص، Install_Voice_Typing.bat را دوباره اجرا کنید.

کیفیت زبان‌ها
-------------
طبق آزمایش‌های سازنده، تشخیص گفتار انگلیسی به‌مراتب بهتر است. پشتیبانی دری افغانستان در این نسخه ضعیف است و ممکن است متن دری خطاهای زیادی داشته باشد. برای کار مهم یا رسمی، نتیجه دری را حتماً بازبینی کنید.

اگر نصب خطا داد
----------------
1. اتصال اینترنت را بررسی کنید.
2. Install_Voice_Typing.bat را دوباره اجرا کنید.
3. فایل install-pip.log را برای خطاهای کتابخانه‌ها بررسی کنید.
4. اگر برنامه باز و فوراً بسته شد، Run_Voice_Typing.bat را اجرا کنید تا خطاها در CMD دیده شوند.
5. اگر خطای سازگاری PyAV/Faster-Whisper دیدید، repair_desktop_pyav.bat را اجرا کنید.
6. بررسی کنید فایل‌های config.json، model.bin، tokenizer.json و vocabulary.txt در models\small موجود باشند.

انتشار در GitHub
----------------
- README.md انگلیسی را برای صفحه اصلی GitHub نگه دارید.
- مدل و محیط .venv را به GitHub آپلود نکنید؛ نصب‌کننده مدل را از Hugging Face می‌گیرد.
- فایل backend\local_config.json خصوصی است و نباید منتشر شود. نصب‌کننده برای هر کمپیوتر توکن جدید تولید می‌کند.
- پوشه data شامل تاریخچه محلی کاربران است؛ محتوای آن را منتشر نکنید.
- Git برای مدیریت نسخه کد است و GitHub برای میزبانی مخزن. لازم نیست سرور شخصی داشته باشید.

فایل‌های اصلی
-------------
Install_Voice_Typing.bat : نصب خودکار Python، کتابخانه‌ها و مدل
Start Voice Typing.vbs   : اجرای برنامه بدون نمایش پنجره CMD
Run_Voice_Typing.bat     : اجرای برنامه با امکان دیدن خطاهای CMD
Run_Backend.bat          : اجرای بک‌اند API محلی به‌صورت اختیاری
repair_desktop_pyav.bat  : تعمیر احتمالی ناسازگاری PyAV
README.md                : راهنمای انگلیسی برای GitHub
DOWNLOAD_AND_INSTALL_FROM_GITHUB_TEMPLATE.bat : راه‌انداز تک‌فایلی؛ پیش از انتشار باید نشانی مخزن در آن تنظیم شود
app.ico                   : آیکن اختصاصی برنامه و نوار وظیفه
